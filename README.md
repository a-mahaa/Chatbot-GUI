# Chatbot-GUI

Description:
This project is a chatbot assistant built with Python and a GUI interface. The chatbot connects to Google Sheets to retrieve FAQ data and uses fuzzy matching to respond to user questions.

Language Used:
Python

Libraries Used:
Tkinter
Pandas
gspread
oauth2client
fuzzywuzzy

Features:
- GUI chatbot application
- Google Sheets integration
- FAQ response system
- Fuzzy text matching
- User and chatbot chat display
- Scrollable chat window
